# Прототип локального сервиса подписания

[Открыть прототип](https://akabanov1983-hue.github.io/local-agent-signing/)

Автономный HTML-прототип интерфейса локального сервиса подписания. Включает задачи на подписание, архив, сертификаты, настройки и журнал операций.

Все данные демонстрационные. Подписание, передача документов и системные диалоги имитируются. Настоящие ключи и пароли не используются. Изменения хранятся в памяти страницы и сбрасываются при её перезагрузке.

Редакция прототипа: 03.11.2026. Основа интерфейса — сохранённый снимок исходного кода от 29.10.2026; журнал операций является проектным дополнением.

## Локальный просмотр

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

Источник публикации: ветка `main`, каталог `/ (root)`.
