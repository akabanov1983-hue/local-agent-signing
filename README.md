# Прототип локального сервиса подписания

[Открыть прототип](https://akabanov1983-hue.github.io/local-agent-signing/)

Целевой демонстрационный интерфейс по согласованным требованиям от 03.11.2026. Основа оформления — снимок develop 1383ab46.

- Сохранение выбора файлов и частичное подписание задач, включая ГЭДК.
- Продолжение пакета после ошибки отдельной задачи и после пропуска просроченной задачи.
- Остановка пакета при отмене подготовки и истечении четырёхчасовой сессии.
- Раздельные результаты формирования и передачи P7S по файлам.
- Сохранение выбора сертификата после перезапуска; повторное подтверждение ввода после завершения сессии.
- Журнал с поиском, фильтрами и сроком хранения 1–999 дней, по умолчанию 30 дней.
- Подтверждение обновления и отложенная установка после обработки пакета.

Все данные демонстрационные. Криптография, передача, копирование исходников, обновление и системные диалоги имитируются. Реальные ключи и пароли не используются. Выбор сертификата сохраняется в браузере; настройки и журнал действуют до перезагрузки страницы.

## Проверка сценариев

Панель «Сценарии» позволяет показать ошибки, просрочку, завершение сессии и результаты проверки обновления.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.
