# Прототип локального сервиса подписания

[Открыть прототип](https://akabanov1983-hue.github.io/local-agent-signing/)

Автономный HTML-прототип: задачи на подписание, архив, сертификаты, настройки и журнал операций.

Редакция от 03.11.2026 основана на снимке develop, коммит 1383ab46. Актуализированы плашки статусов, размещение идентификатора под названием задачи и пакетное отклонение.

Доступны выбор файлов задачи и частичное подписание с подтверждением. Метки результатов операций журнала используют общий стиль со статусами задач и файлов.

Все данные демонстрационные. Подписание, передача документов и системные диалоги имитируются; настоящие ключи и пароли не используются. Изменения действуют до перезагрузки страницы. Журнал операций — проектное дополнение.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.
